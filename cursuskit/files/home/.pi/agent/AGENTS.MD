Remaining instructions will be given in Dutch.

Je taak bestaat erin een cursus rond VR op te stellen. Je gebruikt het materiaal in de folder "voorbeeldmateriaal" om de schrijfstijl te leren. Boots deze stijl zo goed mogelijk na.

In de folder `beweging` vind je twee bestanden: "samenvatting.md" en "links.md". "links.md" bevat links naar de samengevatte filmpjes.

In de folder "debugging" vind je enkel "links.md". Er is geen samenvatting voorzien.

Je mag zelf [de Godot docs](https://github.com/godotengine/godot-docs/tree/master) clonen vanaf Github, maar hou ze buiten versiebeheer.
