# Afbeeldingsbronnen

De vijf afbeeldingen in de les zijn frames van Bastiaan Olijs Godot XR Tools-video's. Ze zijn uitgesneden uit de YouTube-tijdlijnvoorvertoning op 160 × 90 pixels. De tijdcodes openen de video bij het oorspronkelijke frame.

| Bestand | Videoframe |
| --- | --- |
| `video-kubus-highlight.jpg` | Gele omtrek rond de kubus. [Deel 2, 4:35](https://www.youtube.com/watch?v=u66RwHdpeuQ&t=275s). |
| `video-kubus-hand.jpg` | Handpreview bij de kubus. [Deel 2, 5:55](https://www.youtube.com/watch?v=u66RwHdpeuQ&t=355s). |
| `video-bijl-ring.jpg` | Ring en bijlsilhouet op de snapzone. [Deel 3, 5:30](https://www.youtube.com/watch?v=UUwpEY_S9os&t=330s). |
| `video-playerbody.jpg` | Zichtbare zones aan de speler. [Deel 3, 8:15](https://www.youtube.com/watch?v=UUwpEY_S9os&t=495s). |
| `video-snapzone-animatie.jpg` | Snapzone en animatietijdlijn. [Deel 3, 11:00](https://www.youtube.com/watch?v=UUwpEY_S9os&t=660s). |

De oudere PNG-bestanden in deze map komen uit de XR Tools-documentatie. De oorspronkelijke bestanden staan in de mappen [pickup](https://github.com/GodotVR/godot-xr-tools/tree/docs/assets/img/pickup), [pickable](https://github.com/GodotVR/godot-xr-tools/tree/docs/assets/img/pickable), [grab_point](https://github.com/GodotVR/godot-xr-tools/tree/docs/assets/img/grab_point) en [snap_zone](https://github.com/GodotVR/godot-xr-tools/tree/docs/assets/img/snap_zone).
