# Codevoorbeelden

Kies per component één taal. Het addon-script blijft op de pickable-root staan. Onze scripts komen op de nodes die de [les](../cursus.md) aanwijst. Dit zijn losse lescomponenten, geen volledig startproject.

| Component | GDScript | C# |
| --- | --- | --- |
| Lamp bedienen | [lamp.gd](gdscript/lamp.gd) | [Lamp.cs](csharp/Lamp.cs) |
| Magazijnvoorraad | [magazine.gd](gdscript/magazine.gd) | [Magazine.cs](csharp/Magazine.cs) |
| Kamer en projectiel | [chamber.gd](gdscript/chamber.gd) | [Chamber.cs](csharp/Chamber.cs) |
| Begrensde slede | [slide.gd](gdscript/slide.gd) | [Slide.cs](csharp/Slide.cs) |
| Projectiel opruimen | [projectile.gd](gdscript/projectile.gd) | [Projectile.cs](csharp/Projectile.cs) |

Gebruik de C#-bestandsnamen zoals vermeld: ze komen overeen met de klassennamen. Vul alle geëxporteerde nodereferenties in de Inspector in. De code is met documentatie en addonbroncode vergeleken, maar niet gecompileerd of met XR-hardware uitgevoerd.
